# 知序 · DailyInfo

面向 AI 工程师兼投资者的中文情报工作台。覆盖美股、A 股、港股、ETF、AI 新闻、论文及开源项目。电脑与手机可用，时间统一显示为北京时间。

## 已实现

- 有阅读终点的简报；24 小时 / 7 天 / 31 天筛选、搜索、5/10/15 分钟阅读密度。
- 三地市场报价、观察列表、60 秒可见页面轮询；报价脚本在无同源权限的沙箱 iframe 中运行。
- ETF 基准、风险框架、日线、区间价格变化、最大回撤、年化波动率、同市场相关性对比。
- 论文 / Repo、原始链接、来源状态、主题材料分布；不把热度声称为已验证趋势。
- OpenAI 兼容 AI 研究侧栏：引用材料、持续追问、取消请求、错误反馈。
- 收藏、主题关注、明暗主题。个人偏好仅保存在当前设备，不跨设备同步。
- GitHub Pages + Actions：代码推送自动部署；每小时第 17、47 分钟计划采集，调度可能延迟。

## 本地运行

需要 Node.js 22+、Python 3.12+ 和 curl。采集器仅使用 Python 标准库。

```sh
npm ci
python3 scripts/collect.py
npm run dev
```

```sh
npm test
npm run build
```

`config/instruments.json` 管理证券池；`scripts/collect.py` 管理来源与采集；`src/domain.ts` 定义透明的量化指标。

## AI 配置

交互式问答：在网站「工作台设置」填写 API 地址、模型及个人密钥。默认地址 `https://api.deepseek.com`，模型 `deepseek-v4-flash`，可自行替换兼容服务。请求直接发往所填服务；接口需允许浏览器跨域访问。密钥只在当前页面内存中，刷新后清除，不写入 localStorage、代码或 GitHub。不要在公开设备中输入密钥。

自动中文摘要：在 GitHub 仓库 Settings → Secrets and variables → Actions 中设置：

| 类型 | 名称 | 值 |
| --- | --- | --- |
| Secret | `AI_API_KEY` | 你的服务密钥 |
| Variable | `AI_BASE_URL` | 如 `https://api.deepseek.com` |
| Variable | `AI_MODEL` | 如 `deepseek-v4-flash` |

然后在 Actions 中手动运行「更新情报并部署」。自动分析每次最多 12 条新材料，已有有效分析复用。未配置密钥、模型失败或限额时展示原始摘要，不生成假分析。交互密钥与 Actions Secret 独立，不会把仓库 Secret 交给浏览器。

GitHub Pages 是公开静态托管。若需要多设备私密研究同步、密钥托管、可靠实时推送，需要另接经过身份验证的后端；本版本没有暗中搭建外部服务器。

## 数据与限制

- 腾讯财经：公开参考报价与前复权日线，可能延迟或不可用，不是交易所授权的逐笔实时数据。按报价本身的时间显示，并将纽约时间按夏令时规则换算为北京时间。
- 量子位、IT之家、Google AI 等来源：保留标题、短摘要与原文链接；证券时报公开快讯提供市场材料。
- arXiv 原始订阅与 Papers Cool 论文索引分别标注状态。通过第三方索引取得的论文元数据不标成独立验证或已读全文。
- GitHub 项目发现基于近期更新的 LLM 主题项目，非全站增长榜。Star 净增仅覆盖两次观测之间的区间。
- 主题标签属于规则分类；导航中的「趋势雷达」当前是证据分布，不宣称已经检测到可信长期趋势。
- ETF 区间表现是各自币种的前复权价格变化，不等同于含分红总回报。波动率以样本日对数收益标准差乘 √252；最大回撤是观察窗口内峰谷损失。跨市场相关性不计算，观察日不足不计算。
- 未接入的基金净值、费率、持仓权重、跟踪误差和溢折价均明确显示缺失，不估造。产品中的风险说明为通用研究框架，不是个性化交易建议。
- 来源失败时保留旧数据及时间。数据快照最多保留 35 天、600 条材料。日线覆盖约 260 个交易日。来源历史不足时显示实际覆盖范围。
- 证券池为可修改的观察示例，不代表推荐或用户实际持仓。

数据源均可能调整接口或使用条件。本站按个人研究用途设计，不保证第三方可用性，不托管新闻或论文全文。

## GitHub 部署

仓库 Pages 的 Build and deployment 选择 GitHub Actions，工作流 `.github/workflows/publish.yml` 会运行测试、采集、构建并发布。只部署 `dist/`，不会把源代码、配置文件或 Secrets 当成网站内容。

公共仓库的计划任务可能因长期无活动而停用；请检查 Actions 状态。页面底部和来源状态面板会保留真实快照时间，避免静默过期。

产品提案与竞品研究保存在 `docs/`；当前实现以本 README 的范围为准。
